## Linux Distributions 🐧

- [Bunsen Labs](https://www.bunsenlabs.org/) Debian-based with Openbox desktop. Stable, lightweight, CrunchBang heirs.
- [Debian](https://www.debian.org/) The mother of all distros.
- [Fedora](https://getfedora.org/) The Red Hat fan version.
- [Manjaro](https://manjaro.org/) Arch-based but simplifies many tasks with a functional Linux installation from first boot.
- [PeppermintOS](https://peppermintos.com/) Lightweight distro for low-resource hardware.
- [Rocky Linux](https://rockylinux.org/)
- [Ubuntu](https://ubuntu.com/) One of the best distros for Linux newcomers.

## SRE / DevOps Blogs ⚙️

- [SRE Weekly](https://sreweekly.com/) Weekly newsletter about Site Reliability Engineering.
- [The SRE Book — Google](https://sre.google/sre-book/) The definitive SRE reference book, freely available online.
